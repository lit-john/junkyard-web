Junkyard prototype

A work-in-progress scrapyard scene built in Blender and Unity. Feedback welcome.

  • Latest build 2026-10-30 11:59 · 27.3 MB · source 65978b5-dirty

    First shared build: block-out yard with the photoreal drum, cars, crushed cars, scrap, site cabin and tyres.

Controls

Desktop browser with a mouse and keyboard (Chrome, Edge or Firefox). Click the game to capture the mouse and look around; WASD to move, Shift to run, Space to jump; Esc releases the mouse. Mouse capture is still rough: if the view stops following the mouse, click outside the game and back in, or reload the page. The first load is about 25 MB.
